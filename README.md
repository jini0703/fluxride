# FluxRide

FluxRide is a real-time ride-hailing platform featuring explainable driver dispatch, geospatial search, live ride tracking, and a dispatch algorithm benchmarking lab.

## Features

- **Rider App:** Search, book, and track rides.
- **Driver App:** Receive requests, accept rides, and update statuses.
- **Operations Tower:** Monitor fleet in real-time, benchmark dispatch strategies, and simulate demand.
- **Smart Dispatch:** Configurable and explainable algorithms.

## Quick Start

1. `pnpm install`
2. `cp .env.example .env`
3. `docker-compose up -d`
4. `pnpm dev`

For more details, see the `docs/` directory.
